# Reproduction notes

## Model and checkpoints

The release preserves the operator definitions and state-dictionary names of the retained IADA-Net implementation. The query model contains 93,510,354 parameters; only the 590,592 parameters of `row_pooling.context_proj` are trained in query adaptation. The base network remains in evaluation mode during this stage, while gradients pass through its fixed classification operations to the adapter.

The portable loader supports tensor state dictionaries, checkpoints with a `model_state_dict`, and the `DABI_QUERY_ADAPTER_ONLY` compact format paired with its exact original base checkpoint. It does not require the original machine directory layout. Trained model files are not included in this code release. The retained summary CSVs are reference results, not results generated by the new release tests.

The base-training runner follows the documented configuration and the original full-frame augmentation family. Query adaptation follows the retained horizontal-flip, brightness/contrast, rotation, and affine recipe, with BF16 autocast on CUDA and FP32 evaluation. CPU execution uses FP32. Fresh training is not promised to reproduce the original selected weights bit for bit across software versions or hardware; use the original task-trained checkpoint plus its bound adapter for checkpoint replay.

## Controlled heads

The four heads preserve the original capacity calculation, including the gated attention scorer. Fixed views use a SHA256-derived seed based on dataset, sample ID and view. Epoch image order, view selection and dropout seeds follow the recorded matched-head conventions. Training uses FP32, AdamW, a constant learning rate of 0.0001, and validation F1/AUC selection including epoch zero.

`cache_features` streams an N x views x 257 x 768 FP32 array to disk. At eight views, caches can occupy several gigabytes. The sidecar JSON records sample order; training and evaluation reject an order mismatch.

`evaluate_heads` reorders the already extracted patch tokens while preserving CLS. For resolution experiments, area-downsample the full 224 x 224 input to 168, 112, or 56 pixels per side, then restore it to 224 with bilinear interpolation before encoder inference. `probes.py` provides the original feature-order seed convention and query overrides, including matching the RMS change in row-centered attention logits.

## Statistics

The decision rule is malignancy probability greater than 0.5. Internal aggregate CSVs use population SD across five folds. External ensembles average probabilities across source folds and then across images per patient. Bootstrap uses multinomial patient counts, a 95% percentile interval, and common draws for paired differences. The full-model and matched-head seed namespaces are separate, matching the retained study. The `bootstrap` function accepts reference predictions for paired comparisons.

## Source relationship

`layers.py` retains the depth encoding, row pooling and interaction operators from the authors' DABI-Net model. The image-conditioned query and backbone interpolation follow the implementation used for the IADA-Net study. The portable training/data/evaluation wrappers remove machine-specific dependencies while preserving the stated configurations and tensor interfaces. The unit tests check neutral initialization, frozen-base gradients, feature-order invariance, capacity matching, query controls, threshold ties and patient aggregation.
